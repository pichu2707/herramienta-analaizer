# Herramientas genéricas para el día a día

Tenemos la herramienta de contenido Golfo que se conecta a través de la API de WordPress, para tener esta API hemos utilizado dos cosas 

1. Creación del usuario y contraseña en WordPress, (te aconsejo no tener le mismo usuario y contraseña que tu acceso por si tienes que revocarlo)
2. El plugin para crear la contraseña y usuario del usuario de la API: [MiniOrange API Authentication](https://plugins.miniorange.com/wordpress-rest-api-authentication)

La herramienta tiene un pre-promt que ayuda para mejorar y no tener que repetir ciertas acciones en los prompts que estamos utilizando, pero esto no deja de ser algo que se puede  mejorar y optimizar para que vaya mejorando teniendo ordenes más concisas y optimizadas.
